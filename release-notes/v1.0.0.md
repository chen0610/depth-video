# Depth Video v1.0.0

首个公开桌面版本，面向 Windows 10 / 11 x64。官方便携包为 CPU 构建，不内置 CUDA 运行库。

## 主要功能

- 使用 Depth Anything V2 Small / Base / Large 生成灰度相对深度视频
- 源码运行时自动启用 NVIDIA CUDA，不可用时回退到 CPU
- 支持 MP4 / MOV、输出分辨率选择、黑白反转和时间平滑
- 可选保留原始音频，导出兼容的 H.264 / AAC MP4
- 便携包内置 Python、CPU 版 PyTorch、ffmpeg 和 Small 模型

## Windows 下载

下载：

- `DepthVideo-Windows-x64-CPU.zip`
- `DepthVideo-v1.0.0-SHA256SUMS.txt`（可选校验）

解压 ZIP 后运行 `DepthVideo\DepthVideo.exe`。需要 NVIDIA GPU 加速时，请按 README 安装 CUDA 版 PyTorch 从源码运行，或使用 `build_windows.ps1 -TorchVariant cu126 -Zip` 自行打包。

## 注意事项

- 此版本尚未进行 Windows 代码签名，可能触发 SmartScreen 提示。
- Small 模型已内置；Base 和 Large 模型首次使用时需要联网下载。
- 官方便携包只使用 CPU，不能通过安装 CUDA Toolkit 原地切换为 GPU。
- macOS 预编译包暂未提供，可从源码运行或在 Mac 上执行 `build_macos.sh`。

完整 SHA-256 见 `DepthVideo-v1.0.0-SHA256SUMS.txt`。
