# Depth Video v1.0.0

首个公开桌面版本，面向 Windows 10 / 11 x64。

## 主要功能

- 使用 Depth Anything V2 Small / Base / Large 生成灰度相对深度视频
- 自动启用 NVIDIA CUDA，不可用时回退到 CPU
- 支持 MP4 / MOV、输出分辨率选择、黑白反转和时间平滑
- 可选保留原始音频，导出兼容的 H.264 / AAC MP4
- 便携包内置 Python、CUDA 版 PyTorch、ffmpeg 和 Small 模型

## Windows 下载

下载以下三个附件并放在同一目录：

1. `DepthVideo-Windows-x64.zip.001`
2. `DepthVideo-Windows-x64.zip.002`
3. `Assemble-DepthVideo-Windows.cmd`

双击 `Assemble-DepthVideo-Windows.cmd`，校验通过后会生成 `DepthVideo-Windows-x64.zip`。解压并运行 `DepthVideo\DepthVideo.exe`。

由于 GitHub 要求单个 Release 附件小于 2 GiB，2.88 GB 的 Windows 包采用双分卷发布。

## 注意事项

- 此版本尚未进行 Windows 代码签名，可能触发 SmartScreen 提示。
- Small 模型已内置；Base 和 Large 模型首次使用时需要联网下载。
- macOS 预编译包暂未提供，可从源码运行或在 Mac 上执行 `build_macos.sh`。

完整 SHA-256 见 `DepthVideo-v1.0.0-SHA256SUMS.txt`。
